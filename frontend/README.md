# ProcureX — SIH26136 Frontend Prototype

Theme: **10 — Deep Indigo**

Brand: **ProcureX** with the selected PX-style mark.

## Prototype honesty
The interface intentionally contains a small amount of **SYNTHETIC DEMO DATA** so the complete workflow can be demonstrated during judging. Prototype/demo banners identify illustrative records. These values are not presented as production government or startup records.

## Workflow
Government Registration → Government account registered successfully → Government Home → Challenge Builder → Problem statement successfully registered → Discovery → Proposal Comparison → AI-assisted Recommendation → Pilot & KPI → Final Decision.

Startup Home → Startup Registration → Challenge Discovery → Challenge Detail → Interest → Proposal → Pilot.

Public → Innovation Hub.

## Backend integration
The screens remain plain HTML/CSS/JS and use localStorage for prototype state. Replace the localStorage functions with API calls without changing the screen model. Suggested future endpoints include `/api/government`, `/api/challenges`, `/api/startups`, `/api/proposals`, `/api/pilots`, and `/api/decisions`.

## Run
Open `index.html` in a browser. No build step is required.
